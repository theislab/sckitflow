## Installation

You need to have Python 3.10 or newer installed on your system.
If you don't have Python installed, we recommend installing [uv][].

There are several alternative options to install sc-flow-tools:

<!--
1) Install the latest release of `sc-flow-tools` from [PyPI][]:


-->

1. Install the latest development version:

```bash
pip install git+https://github.com/lorenzo-consoli/sc-flow-tools.git@main
```
